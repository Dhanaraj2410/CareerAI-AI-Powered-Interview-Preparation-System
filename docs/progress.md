# Progress tracking

CareerAI's dashboard reports measured progress from completed practice activity.
It does not substitute sample scores for missing data.

## What is measured

- Aptitude: the latest aptitude assessment percentage.
- Resume: the latest uploaded resume ATS score.
- Technical: the latest completed mock interview score.
- Communication: the latest completed mock interview confidence score.

The overall score averages only dimensions that have a real result. A new
candidate therefore sees an unstarted state instead of an artificial average.

The preparation pulse covers the current day and the previous six calendar
days. It counts aptitude assessments, coding submissions, interviews, group
discussions, and resume uploads. The next action is selected from the first
missing baseline, then from the weakest measured area.
